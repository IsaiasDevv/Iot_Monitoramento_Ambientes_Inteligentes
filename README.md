## 🧠 Sobre o Projeto

Este projeto foi desenvolvido como parte do **Projeto Integrador V – B** da PUC Goiás, com o objetivo de criar um sistema inteligente capaz de monitorar ambientes em tempo real.

💡 A solução integra:

- 🔌 **Arduino (IoT)**
- ☕ **Java (Processamento)**
- 🎨 **Interface gráfica (UI/UX)**

📊 O sistema monitora:

- 🌡️ Temperatura  
- 💧 Umidade  
- 💡 Luminosidade
