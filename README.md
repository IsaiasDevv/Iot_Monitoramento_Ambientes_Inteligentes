## 📖 Sobre o Projeto

O **Smart IoT Environment Monitoring System** é um sistema desenvolvido para monitorar condições ambientais em tempo real utilizando sensores físicos conectados a um Arduino.

Este projeto foi desenvolvido como parte do **Projeto Integrador V – B** do curso de **Análise e Desenvolvimento de Sistemas**, com o objetivo de aplicar na prática conhecimentos de programação, hardware e desenvolvimento de sistemas.

---

## 💡 O que é este projeto?

Este sistema simula uma **casa inteligente (Smart Home)**, permitindo monitorar o ambiente automaticamente.

Com ele é possível:

- 🌡️ Monitorar temperatura  
- 💧 Monitorar umidade  
- 💡 Monitorar luminosidade  
- 📊 Visualizar dados em tempo real  

---

## 🎯 Para que serve?

O sistema pode ser aplicado em:

- 🏠 Residências inteligentes  
- 🌱 Estufas agrícolas  
- 🏢 Empresas  
- ⚡ Controle de energia  
- 🌍 Projetos de automação  

---

## 🧠 Como funciona?

O sistema funciona em etapas simples:

1. 📡 Sensores coletam os dados do ambiente  
2. 🔌 Arduino recebe e envia os dados  
3. 💻 Java processa as informações  
4. 📱 Interface exibe para o usuário
